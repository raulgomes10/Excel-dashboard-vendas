# Dashboard de Vendas de Serviços de Assinaturas (Xbox) - Excel

Repositório criado para documentar a reprodução de um dashboard interativo de vendas no Excel do Expert Felipe Aguiar, com foco na organização, tratamento e visualização de dados voltada para a tomada de decisões de negócios. Alteração no avatar, visual da ferramenta e no nome do gráfico para “SUBSCRIPTIONS XBOX GAME PASS”. Adicionado o “botão TOTAL SUBSCRIPTIONS XBOX GAME PASS” e mais uma pergunta de negócio e seu respectivo “botão resposta”.

##  Objetivo do Projeto
Transformar dados brutos em informações visuais claras, dinâmicas e úteis, permitindo uma análise eficaz do desempenho de vendas a partir de uma base de dados fictícia de serviços de assinaturas (como Xbox Game Pass, EA Play e Minecraft Season Pass).

##  Estruturação e Desenvolvimento
A ferramenta foi construída integrando materiais de apoio, tabelas dinâmicas e elementos visuais interativos:
- **Base de Dados:** Utilização de uma base de dados fictícia de assinaturas para alimentar toda a modelagem.
- **Tabelas Dinâmicas:** Criação de tabelas específicas estruturadas para responder diretamente às principais perguntas de negócio do projeto.
- **Estruturação de Abas:** Organização inicial com abas de apoio para o cálculo, tratamento e estruturação dos dados antes da exibição final no painel.

##  Componentes do Dashboard
O painel interativo foi desenhado para ser totalmente dinâmico, contando com os seguintes recursos:
1. **Menu de Filtros Dinâmicos:** Filtro principal por tipo de assinatura (**"Subscription Type"**), integrado aos botões **Annual**, **Monthly** e **Quarterly**.
2. **”Botões” de Indicadores e Gráfico Dinâmico:**
   - **”Botão 1”:** TOTAL SUBSCRIPTIONS XBOX GAME PASS, planos anuais (agregando todas as assinaturas).
   - **Gráfico de Barra:** SUBSCRIPTIONS XBOX GAME PASS, planos anuais segmentado por status de renovação (com ou sem auto renovação).
   - **”Botão 3”:** TOTAL SUBSCRIPTIONS EA PLAY SEASON PASS.
   - **”Botão 4”:** TOTAL SUBSCRIPTIONS MINECRAFT SEASON PASS.
   - **”Botão 5’:** TOTAL  COUPON VALUE  XBOX GAME PASS, segmentado por auto renovação e não auto renovação.

##  Perguntas de Negócio Respondidas
A ferramenta foi projetada para solucionar os seguintes questionamentos estratégicos:
1. Qual o faturamento total de vendas de planos anuais?
2. Como se divide o faturamento de planos anuais entre auto renovação e não auto renovação?
3. Qual é o total de vendas de assinaturas do EA Play?
4. Qual é o total de vendas de assinaturas do Minecraft Season Pass?
5. Qual é o valor total de cupons (*Coupon Value*), separado por auto renovação e não auto renovação?
